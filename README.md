# Iceberg Client

Бело-голубой лаунчер для Minecraft: вход по нику, общий чат, подписки.

Этот репозиторий — источник автообновлений. Лаунчер при запуске проверяет
последний релиз (Releases → Latest) и скачивает из него файл `IcebergClient.exe`.

## Как выпустить новую версию
1. Создать релиз с тегом вида `v0.3.1` (номер больше текущего).
2. Прикрепить к нему файл `IcebergClient.exe` (имя должно быть именно таким).
3. Опубликовать. Лаунчеры обновятся при следующем запуске.
