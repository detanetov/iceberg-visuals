# Iceberg Client

Бело-голубой лаунчер для Minecraft: вход по нику, общий чат, подписки.

Этот репозиторий — источник автообновлений. При запуске лаунчер читает
`latest.json` из ветки `main` и, если там версия новее, скачивает `IcebergClient.exe`,
проверяет контрольную сумму SHA-256 и перезапускается.

## Как выпустить новую версию
1. Заменить `IcebergClient.exe` новой сборкой (номер версии внутри должен быть больше).
2. В `latest.json` обновить `version`, `size` (размер файла в байтах) и `sha256`
   (в Windows: `certutil -hashfile IcebergClient.exe SHA256`).
3. Закоммитить оба файла в `main`. Лаунчеры обновятся при следующем запуске
   (GitHub может отдавать старый файл ещё до 5 минут).

Если `latest.json` нет, лаунчер смотрит последний релиз (Releases → Latest)
с файлом `IcebergClient.exe`.
